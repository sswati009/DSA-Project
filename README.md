# Data Structures and Algorithms (DSA) Projects

## Title
Data Structures and Algorithms (DSA) Projects in C

## Objective
To implement and understand various Data Structures and Algorithms using the C programming language. This repository focuses on improving problem-solving skills, algorithmic thinking, and coding efficiency through practical implementations.

## Problem Statement
Develop and implement various Data Structures and Algorithms such as Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, Searching, and Sorting techniques using C programming.

## Algorithms Used

1. Read the problem statement.
2. Select the appropriate data structure or algorithm.
3. Design the solution.
4. Implement the logic in C.
5. Compile and execute the program.
6. Test using different inputs.
7. Analyze the time and space complexity.

## Time Complexity

| Algorithm | Time Complexity |
|-----------|-----------------|
| Linear Search | O(n) |
| Binary Search | O(log n) |
| Bubble Sort | O(n²) |
| Selection Sort | O(n²) |
| Insertion Sort | O(n²) |
| Merge Sort | O(n log n) |
| Quick Sort | O(n log n) (Average) |
| BFS | O(V + E) |
| DFS | O(V + E) |

## Space Complexity

| Algorithm | Space Complexity |
|-----------|------------------|
| Arrays | O(n) |
| Linked List | O(n) |
| Stack | O(n) |
| Queue | O(n) |
| Merge Sort | O(n) |
| Quick Sort | O(log n) (Recursive Stack) |
| Graph (Adjacency Matrix) | O(V²) |
| Graph (Adjacency List) | O(V + E) |
